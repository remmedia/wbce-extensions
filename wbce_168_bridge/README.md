# WBCE-1.6.8-Bridge

Die Bridge stellt gemeinsam mit der Hook-Bridge wiederverwendbare Adapter für
Datenbankzugriffe, HTML-Escaping und sichere interne Weiterleitungen bereit.
Vorhandene WBCE-1.7-Kernfunktionen werden nie überschrieben. Module können ihre
lokalen 1.6.8-Fallbacks schrittweise durch diese zentralen Funktionen ersetzen.
